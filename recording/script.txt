# 录音稿：给"声音克隆 + 越用越像我"攒数据
#
# 怎么读：
# - 像平常讲话一样，别播音腔。读错了、笑场了、卡住了都没关系，重来一句就好，自然的停顿和语气词正是要学的。
# - 英文按你平时的念法念，不用刻意标准。你的口音就是你声音的一部分。
# - 每段 3–5 分钟，一次读一两段就休息，嗓子累了声音会变。尽量同一个房间、同一支麦克风、离嘴巴一个拳头远。
# - 读稿的部分文字是已知的，不用再校对；最后一段「自由讲」是回忆访谈，讲多久都行，会后在纠错页面校对文字。
#
# 稿子里的双语切换类型（每段都会混着出现）：
#   [插词]   中文句子里插英文名词：这个 bug 我改好了
#   [动词]   英文动词 + 中文语法：你 check 一下、我 push 上去了、deploy 好了没
#   [句间]   整句切换：好，let's do it.
#   [英夹中] 英文句子里夹中文：I think 这个方向 is right.
#   [缩写]   英文缩写的念法：AI、API、GPU、iOS、PRD
#   [语气]   中英语气词：OK 啦、sorry 哦、nice 啊
#   [引语]   转述别人的英文：他跟我说 "it's too AI"
#   [纯中] [纯英] 不切换的整句，作对照
#
# 格式：## 开头是段落标题；其余每行一句。

# ===== 第二轮：朗读口吻（给念信、念书用）=====
# 前面 1–9 段是聊天口吻，念信念书时克隆的声音不够像你。这几段专门攒「念给人听」的声音：
# - 比平常说话慢一点，平稳、清楚，可以有感情，但不用播音腔。想象念给孩子或家人听。
# - 每句一口气读完（都在 10 秒以内），句中的逗号自然停一下就好。
# - 读错了就重录这一句。古文按你习惯的读音念，不确定的字跳过也行。
# - 11–15 段共 86 句，人声约 10 分钟，可以分几次读。

## 12 朗读：睡前故事（有对话，可以带一点表情）
从前，在一座很高的山上，住着一只很小很小的狐狸。
小狐狸每天晚上都坐在山顶，抬头看天上的星星。
有一天，它问妈妈：“星星为什么不会掉下来呀？”
妈妈笑着说：“因为每一颗星星，都有人在想着它。”
小狐狸想了想，又问：“那会不会有人，也在想着我呢？”
妈妈把它抱进怀里：“当然有啊，我每天都在想着你。”
第二天，小狐狸决定下山，去看看山下的世界是什么样子。
它走过一片金黄色的麦田，麦子在风里轻轻地摇。
它遇见了一只老乌龟，老乌龟慢慢地说：“孩子，别着急。”
“路要一步一步走，饭要一口一口吃，日子要一天一天过。”
天黑的时候，小狐狸有一点害怕，也有一点想家。
它抬起头，发现天上的星星，和山顶上看到的一模一样。
于是它知道，不管走到哪里，妈妈都在想着它。
小狐狸笑了，它闭上眼睛，在星星底下慢慢地睡着了。
好了，故事讲完了，你也该闭上眼睛，晚安。
